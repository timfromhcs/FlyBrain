# Security Policy

## Supported Versions
FlyBrain receives active security updates on the `main` branch.

| Version | Supported          |
| ------- | ------------------ |
| 10.0.x  | :white_check_mark: |
| 9.0.x   | :white_check_mark: |

## Reporting a Vulnerability
If you discover a security vulnerability within FlyBrain, please do not open a public issue. Send an email with vulnerability details and reproduction steps to the repository maintainers.
